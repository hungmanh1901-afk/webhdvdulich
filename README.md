# Web Hướng Dẫn Du Lịch

## Giới thiệu
Website đặt hướng dẫn viên du lịch, cho phép người dùng tìm kiếm và đặt lịch với hướng dẫn viên.

## Công nghệ sử dụng
- Laravel (PHP Framework)
- MySQL
- Bootstrap

## Chức năng chính
- Quản lý hướng dẫn viên (CRUD)
- Hiển thị danh sách hướng dẫn viên kèm ảnh
- Đặt lịch hướng dẫn viên
- Phân quyền admin

## Hình ảnh demo
(Thêm ảnh ở đây nếu có)

## Cách chạy project
1. composer install
2. cp .env.example .env
3. php artisan key:generate
4. php artisan migrate
5. php artisan serve
